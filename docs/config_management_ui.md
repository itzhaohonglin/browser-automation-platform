# 配置管理界面使用说明

## 功能概述

配置管理界面提供了完整的采集配置 CRUD 操作，无需直接操作数据库即可管理所有采集任务配置。

## 访问方式

1. 启动服务：`uvicorn app.main:app --reload`
2. 打开浏览器访问：http://127.0.0.1:8000/static/index.html
3. 点击页面右上角的 **"⚙️ 配置管理"** 按钮

## 功能说明

### 1. 查看配置列表

- 显示所有采集配置的摘要信息
- 每个配置卡片包含：
  - 配置名称
  - 启用/禁用状态
  - 是否需要登录
  - 配置 ID
  - 目标 URL
  - 登录态标识（如果需要）
  - 最大翻页数
  - 创建时间

### 2. 新建配置

点击 **"➕ 新建配置"** 按钮，填写以下字段：

#### 必填字段

- **配置名称**：为配置起一个易识别的名称（如：淘宝商品采集）
- **目标URL**：要访问的页面地址
- **输入框配置 (JSON)**：定义要填充的表单字段
  ```json
  {
    "keyword": {
      "selector": "#search-input",
      "value": "{keyword}"
    }
  }
  ```
- **提交按钮选择器**：提交表单的按钮（如：`button[type=submit]`）
- **等待加载选择器**：等待结果加载的元素（如：`.result-list`）
- **字段映射规则 (JSON)**：定义要提取的数据字段
  ```json
  {
    "title": {
      "selector": ".item-title",
      "type": "text"
    },
    "price": {
      "selector": ".item-price",
      "type": "text"
    }
  }
  ```

#### 可选字段

- **需要登录**：勾选此项如果目标网站需要登录
  - 勾选后需填写 **登录态标识**（如：taobao、jd）
  - 可选填写 **登录页URL**
- **下一页选择器**：如果需要翻页，填写下一页按钮选择器
- **最大翻页数**：限制最多抓取的页数（默认 1 页）
- **启用配置**：是否启用此配置（默认勾选）

### 3. 编辑配置

点击配置卡片右侧的 **"✏️"** 按钮，可以修改现有配置的任何字段。

### 4. 删除配置

点击配置卡片右侧的 **"🗑️"** 按钮，删除不再需要的配置。

**注意**：如果配置存在待执行的任务，将无法删除，需要先完成或清理相关任务。

## 字段说明

### 输入框配置格式

```json
{
  "字段名": {
    "selector": "CSS选择器",
    "value": "{参数占位符}"
  }
}
```

- `字段名`：自定义的字段标识
- `selector`：页面上输入框的 CSS 选择器
- `value`：要填充的值，使用 `{参数名}` 作为占位符

### 字段映射规则格式

```json
{
  "字段名": {
    "selector": "CSS选择器",
    "type": "text | attr",
    "attr": "属性名（type=attr时需要）"
  }
}
```

- `字段名`：提取后的字段名称
- `selector`：数据元素的 CSS 选择器
- `type`：提取类型
  - `text`：提取元素的文本内容
  - `attr`：提取元素的属性值
- `attr`：当 `type=attr` 时，指定要提取的属性名（如 `href`、`src`）

## 示例配置

### 示例 1：简单搜索采集

```json
// 输入框配置
{
  "keyword": {
    "selector": "#search-box",
    "value": "{keyword}"
  }
}

// 字段映射规则
{
  "title": {
    "selector": ".result-title",
    "type": "text"
  },
  "link": {
    "selector": ".result-link",
    "type": "attr",
    "attr": "href"
  }
}
```

### 示例 2：需要登录的采集

- 勾选 **"需要登录"**
- 填写 **登录态标识**：`taobao`
- 填写 **登录页URL**：`https://login.taobao.com`

在使用此配置前，需要通过登录态管理功能先保存登录态：
1. 调用 `/auth/start?profile=taobao` 打开浏览器
2. 手动完成登录
3. 调用 `/auth/save?profile=taobao` 保存登录态

## API 端点

配置管理功能对应的后端 API：

- `POST /api/configs` - 创建配置
- `GET /api/configs` - 获取配置列表
- `GET /api/configs/{config_id}` - 获取配置详情
- `PUT /api/configs/{config_id}` - 更新配置
- `DELETE /api/configs/{config_id}` - 删除配置

详细的 API 文档请访问：http://127.0.0.1:8000/docs

## 注意事项

1. **JSON 格式验证**：输入框配置和字段映射规则必须是有效的 JSON 格式，否则保存时会提示错误
2. **选择器语法**：支持标准的 CSS 选择器语法
3. **登录态关联**：如果配置需要登录，必须先通过登录态管理保存对应 profile 的登录态
4. **删除限制**：存在待执行任务的配置无法删除，需要先处理完相关任务
5. **分页支持**：配置列表每页显示 10 条记录，支持翻页查看

## 常见问题

### Q: 保存配置时提示 JSON 格式错误

A: 请检查输入框配置和字段映射规则的 JSON 格式是否正确，可以使用在线 JSON 验证工具检查。

### Q: 删除配置时提示存在待执行任务

A: 需要先完成或删除关联的任务，或者修改任务的 config_id 后再删除配置。

### Q: 需要登录但采集失败

A: 请确认：
1. 已通过登录态管理功能保存了对应的登录态
2. auth_profile 字段与保存的登录态文件名一致
3. 登录态未过期

## 下一步

创建配置后，您可以：
1. 在数据库中插入 `job_queue` 记录来创建采集任务
2. 调用 `/task/run` API 手动触发任务执行
3. 等待调度器自动执行失败任务的重试
