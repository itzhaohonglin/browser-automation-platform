# 批处理脚本编码问题修复说明

## 问题描述

执行 `build_release.bat` 时报错：
```
'殑' 不是内部或外部命令，也不是可运行的程序或批处理文件。
命令语法不正确。
```

## 原因分析

Windows 批处理文件（.bat）在中文 Windows 系统上默认使用 **GBK/GB2312 编码**。

原先的批处理文件使用 **UTF-8 编码** 并包含中文注释，导致：
- 中文字符在 Windows CMD 中显示为乱码
- 乱码被当作命令执行，导致"命令不存在"错误

## 解决方案

**移除所有中文注释，使用纯英文**

优点：
- ✅ 完全避免编码问题
- ✅ 跨平台兼容（UTF-8 编码的纯英文批处理在所有 Windows 版本都正常）
- ✅ 国际化友好
- ✅ 无需关心文件编码格式
