## 核心改进

### 1. 端口配置（非硬编码）
```ini
# .env 文件
APP_PORT=8000    # 默认端口
# APP_PORT=9000  # 可自定义任何端口
```

修改方法：
1. 编辑 `.env` 文件
2. 修改 `APP_PORT=新端口`
3. 重启服务（Ctrl+C，再运行 startup.bat）
4. 访问 `http://127.0.0.1:新端口/static/index.html`

**无需重新打包程序！**

### 2. 数据库连接配置
```ini
# .env 文件
DATABASE_URL=mssql+aioodbc://用户名:密码@服务器:端口/数据库?driver=ODBC+Driver+17+for+SQL+Server
```

支持：
- 本地/远程数据库
- 不同的用户名和密码
- 不同的服务器地址和端口
- 密码特殊字符 URL 编码

### 3. 其他可配置项
- 浏览器模式（显示/隐藏窗口）
- 日志级别（DEBUG/INFO/WARNING/ERROR）
- 调试模式（开发/生产）
- 告警通知（邮件、钉钉、企业微信）

## 配置示例

### 示例1：本地开发环境
```ini
DATABASE_URL=mssql+aioodbc://sa:dev123@localhost:1433/bap?driver=ODBC+Driver+17+for+SQL+Server
APP_PORT=8000
DEBUG=true
HEADLESS_MODE=false
LOG_LEVEL=DEBUG
```

### 示例2：生产环境
```ini
DATABASE_URL=mssql+aioodbc://bap_user:SecurePass@db.company.com:1433/bap_prod?driver=ODBC+Driver+17+for+SQL+Server
APP_PORT=9000
DEBUG=false
HEADLESS_MODE=true
LOG_LEVEL=INFO
LOG_FILE=logs/app.log
```

### 示例3：测试环境（密码含特殊字符）
```ini
# 原密码：P@ss#123
# 编码后：P%40ss%23123
DATABASE_URL=mssql+aioodbc://test_user:P%40ss%23123@192.168.1.50:1433/bap_test?driver=ODBC+Driver+17+for+SQL+Server
APP_PORT=8080
DEBUG=false
HEADLESS_MODE=true
LOG_LEVEL=WARNING
```

## 技术实现

### 配置加载机制
```python
# app/core/config.py
class Settings(BaseSettings):
    DATABASE_URL: str
    APP_HOST: str = "0.0.0.0"
    APP_PORT: int = 8000
    DEBUG: bool = False
    HEADLESS_MODE: bool = True
    LOG_LEVEL: str = "INFO"
    # ... 更多配置

    class Config:
        env_file = ".env"
        env_file_encoding = "utf-8"
```

### 应用启动
```python
# app/main.py
if __name__ == "__main__":
    import uvicorn
    uvicorn.run(
        "app.main:app",
        host=settings.APP_HOST,    # 从配置读取
        port=settings.APP_PORT,    # 从配置读取
        reload=settings.DEBUG
    )
```

### PyInstaller 打包
- `.env.template` 会被复制到打包目录作为 `.env.example`
- 程序运行时读取同目录下的 `.env` 文件
- 配置文件与可执行文件分离，便于修改
