## 🔧 代码修改

### app/main.py
```python
def get_base_path() -> Path:
    """获取应用基础路径（兼容开发环境和 PyInstaller 打包）"""
    if getattr(sys, 'frozen', False):
        # PyInstaller 打包后
        base_path = Path(sys._MEIPASS)
    else:
        # 开发环境
        base_path = Path(__file__).parent.parent
    return base_path

# 使用
base_path = get_base_path()
static_dir = base_path / "static"

# Uvicorn 启动
uvicorn.run(
    app,  # 直接传递对象，不用字符串
    host=settings.APP_HOST,
    port=settings.APP_PORT,
    reload=False
)
```

## ⚠️ 已知限制

### 1. Playwright 浏览器驱动
- **问题**：打包后需要手动安装 Playwright 浏览器
- **解决**：客户运行 `install_browser.bat` 或手动执行 `playwright install chromium`
- **原因**：浏览器驱动约 300MB，不适合打包进 exe

### 2. 配置文件
- **问题**：首次运行需要配置 `.env`
- **解决**：启动脚本会自动从模板创建并提示编辑
- **原因**：数据库连接等敏感信息不能硬编码

### 3. 数据库依赖
- **问题**：需要安装 ODBC Driver 17 for SQL Server
- **解决**：在文档中说明，客户端安装向导会检查
- **原因**：系统级驱动无法打包
