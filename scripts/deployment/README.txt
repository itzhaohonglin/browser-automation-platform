1. 系统简介
========================================

本系统是一个配置驱动的浏览器自动化数据采集平台（RPA），
主要功能包括：

✓ 通过配置驱动采集任务，无需修改代码
✓ 支持多站点登录态管理
✓ 自动补跑失败任务
✓ 实时监控和日志推送
✓ Web 可视化管理界面

========================================
2. 安装步骤（首次使用）
========================================

步骤 1：安装 Playwright 浏览器
----------------------------------------
双击运行：install_playwright.bat

这将下载并安装 Chromium 浏览器（约 150MB）
安装时间取决于网络速度，通常需要 2-5 分钟

步骤 2：配置数据库连接
----------------------------------------
1) 用记事本打开 .env 文件
2) 找到 DATABASE_URL 配置项
3) 修改为实际数据库地址

配置格式：
  mysql+aiomysql://用户名:密码@主机地址:端口/数据库名

配置示例：
  DATABASE_URL=mysql+aiomysql://root:123456@localhost:3306/bap

注意事项：
  - 确保 MySQL 数据库已安装并运行
  - 确保数据库 "bap" 已创建
  - 用户需要有完整的数据库权限

步骤 3：初始化数据库（仅首次）
----------------------------------------
如果是全新数据库，需要初始化表结构：

方法 1（推荐）：
  首次运行 start.bat 时会自动初始化

方法 2（手动）：
  在命令行执行：
    alembic upgrade head

3. 启动服务
========================================

日常启动
----------------------------------------
双击运行：start.bat

启动脚本会自动：
  ✓ 检查配置文件是否存在
  ✓ 检查 Playwright 浏览器是否已安装
  ✓ 创建必要的目录（auth_files, logs）
  ✓ 启动 Web 服务

启动成功标志：
  看到 "Application startup complete" 消息

停止服务
----------------------------------------
方法 1：在启动窗口按 Ctrl+C
方法 2：双击运行 stop.bat
方法 3：直接关闭命令行窗口

5. 配置说明
========================================

.env 配置文件
----------------------------------------

必填项：
  DATABASE_URL=mysql+aiomysql://user:pass@host:3306/bap
    数据库连接地址

常用配置：
  APP_PORT=8000
    Web 服务端口，如果 8000 被占用可修改为其他端口

  HEADLESS_MODE=true
    浏览器无头模式
    - true：后台运行，不显示浏览器窗口（生产推荐）
    - false：显示浏览器窗口（调试用）

  LOG_LEVEL=INFO
    日志级别
    - DEBUG：详细调试信息
    - INFO：一般信息（推荐）
    - WARNING：仅警告和错误
    - ERROR：仅错误信息

  DEBUG=false
    调试模式
    - true：开发调试模式，会显示详细错误信息
    - false：生产模式（推荐）

修改配置后需重启服务才能生效

6. 常见问题
========================================

Q1: 提示"端口被占用"
----------------------------------------
错误信息：
  Error: [Errno 10048] error while attempting to bind on
  address ('0.0.0.0', 8000): 通常每个套接字地址只允许使用一次

解决方案：
  方法 1：关闭占用 8000 端口的程序
    - 打开任务管理器
    - 找到占用端口的程序并结束进程

  方法 2：修改服务端口
    - 编辑 .env 文件
    - 修改 APP_PORT=8001（改为其他端口）
    - 重启服务

Q2: 提示"找不到数据库"或"连接被拒绝"
----------------------------------------
错误信息：
  Can't connect to MySQL server
  Connection refused

解决方案：
  1) 确认 MySQL 服务正在运行
     - Windows: 服务管理器中启动 MySQL 服务

  2) 确认数据库已创建
     mysql -u root -p
     CREATE DATABASE bap CHARACTER SET utf8mb4;

  3) 确认 .env 中的配置正确
     - 用户名、密码是否正确
     - 主机地址是否正确（本地用 localhost）
     - 端口是否正确（默认 3306）
     - 数据库名是否正确

Q3: Playwright 浏览器安装失败
----------------------------------------
错误信息：
  Failed to install browsers

解决方案：
  方法 1：检查网络连接
    - 确保能访问国外网站
    - 可以尝试使用代理

  方法 2：手动下载
    - 访问 https://playwright.dev/docs/browsers
    - 按照说明手动下载浏览器

  方法 3：使用国内镜像（如果可用）
    set PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright/
    playwright install chromium

Q4: 任务执行失败
----------------------------------------
错误信息：
  任务状态显示 "failed"

排查步骤：
  1) 查看日志文件
     logs/app.log - 查看详细错误信息

  2) 检查配置
     - 选择器是否正确
     - 登录态是否有效（如需要）
     - 网络是否可访问目标网站

  3) 测试网站
     - 手动访问目标网站，确认可正常访问
     - 检查网站结构是否发生变化

Q5: 登录态失效
----------------------------------------
现象：
  提示需要登录，或采集不到数据

解决方案：
  1) 访问前端看板
  2) 进入"登录态管理"面板
  3) 选择对应的站点配置
  4) 点击"更新登录态"
  5) 在弹出的浏览器中手动登录
  6) 登录成功后点击"确认保存"

Q6: 权限错误
----------------------------------------
错误信息：
  Permission denied
  Access is denied

解决方案：
  以管理员身份运行：
    1) 右键点击 start.bat
    2) 选择"以管理员身份运行"

Q7: 服务无法停止
----------------------------------------
解决方案：
  方法 1：使用 stop.bat

  方法 2：任务管理器
    - 打开任务管理器（Ctrl+Shift+Esc）
    - 找到 browser-automation-platform.exe
    - 结束进程

7. 更新和维护
========================================

更新程序
----------------------------------------
1. 备份重要数据
   - 备份 auth_files/ 目录（登录态）
   - 备份 .env 配置文件
   - 备份数据库
     mysqldump -u root -p bap > backup.sql

2. 停止服务
   - 运行 stop.bat
   - 或关闭服务窗口

3. 替换程序文件
   - 解压新版本文件
   - 覆盖除以下文件外的所有文件：
     * .env（保留原配置）
     * auth_files/（保留登录态）

4. 更新数据库（如有需要）
   alembic upgrade head

5. 重启服务
   - 运行 start.bat

日常维护
----------------------------------------

定期备份（建议每周）：
  1) 备份数据库
     mysqldump -u root -p bap > backup_20241230.sql

  2) 备份登录态
     复制 auth_files/ 目录

清理日志（建议每月）：
  - 删除或归档 logs/ 目录中的旧日志
  - 保留最近 30 天的日志即可

监控运行状态：
  - 定期访问健康检查接口
  - 查看前端看板统计数据
  - 检查失败任务情况
