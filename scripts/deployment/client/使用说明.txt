====================================
  浏览器自动化平台 - 使用说明
====================================

版本：v1.0.0
更新日期：2026-09-30

====================================
一、系统简介
====================================

这是一个配置驱动的浏览器自动化数据采集平台（RPA），可以通过配置数据库来实现对不同网站的数据采集，无需修改代码。

主要特性：
  ✓ 配置驱动：一次配置，多次使用
  ✓ 登录态管理：支持多站点登录态隔离
  ✓ 自动重试：失败任务自动补跑
  ✓ 实时监控：WebSocket 实时推送任务状态
  ✓ 复杂页面：支持 iframe、弹窗、分页

====================================
二、首次安装步骤
====================================

1. 解压安装包
   将整个文件夹解压到任意位置（建议英文路径）

2. 运行安装脚本
   双击 install.bat，按照提示完成安装

3. 配置数据库和服务
   编辑 .env 文件，修改以下配置：

   【数据库连接】（必填）
   DATABASE_URL=mssql+aioodbc://用户名:密码@服务器地址:端口/数据库名?driver=ODBC+Driver+17+for+SQL+Server

   示例（本地）：
   DATABASE_URL=mssql+aioodbc://sa:MyPassword123@localhost:1433/bap?driver=ODBC+Driver+17+for+SQL+Server

   示例（远程）：
   DATABASE_URL=mssql+aioodbc://dbuser:SecurePass@192.168.1.100:1433/bap?driver=ODBC+Driver+17+for+SQL+Server

   【服务端口】（可选，默认 8000）
   APP_PORT=8000

   修改端口后访问地址：http://127.0.0.1:新端口/static/index.html

4. 创建数据库
   在 SQL Server 中执行：
   CREATE DATABASE bap COLLATE Chinese_PRC_CI_AS;

5. 初始化数据库表
   运行 init_database.bat

6. 安装浏览器驱动（约300MB，仅需一次）
   运行 install_browser.bat

====================================
三、启动服务
====================================

1. 双击 startup.bat 启动服务

2. 等待服务启动完成（看到"Application startup complete"）

3. 访问监控看板
   打开浏览器，访问：http://127.0.0.1:8000/static/index.html

4. 停止服务
   在控制台窗口按 Ctrl+C

四、功能说明
====================================

【监控看板】（http://127.0.0.1:8000/static/index.html）
  - 实时查看任务统计
  - 查看正在执行的任务
  - 查看执行日志
  - 管理任务和配置

【API 文档】（http://127.0.0.1:8000/docs）
  - 查看所有 API 接口
  - 在线测试接口
  - 查看参数说明

【核心功能】
  1. 配置管理
     - 创建采集配置（定义目标网站、提取规则）
     - 编辑配置
     - 启用/禁用配置

  2. 任务管理
     - 创建单个任务
     - 批量导入任务
     - 手动执行任务
     - 查看任务结果

  3. 登录态管理
     - 更新登录态（需要登录的网站）
     - 登录态自动加载
     - 多站点隔离

  4. 自动调度
     - 失败任务自动重试（最多3次）
     - 每30分钟扫描一次
     - 按优先级执行

====================================
五、典型使用流程
====================================

【方式一：使用界面】

1. 启动服务（startup.bat）

2. 访问监控看板

3. 创建配置
   - 点击"配置管理" → "新增配置"
   - 填写目标网址、选择器规则
   - 保存配置

4. 创建任务
   - 点击"任务管理" → "新增任务"
   - 选择配置
   - 填写查询参数
   - 提交任务

5. 查看结果
   - 任务自动执行
   - 实时查看日志
   - 查看采集结果

【方式二：使用脚本】

1. 启动服务（startup.bat）

2. 初始化配置（首次）
   运行 init_config.bat

3. 批量导入任务
   - 准备 TXT/CSV 文件（每行一个注册证号）
   - 运行 batch_import.bat
   - 任务自动执行

七、常见问题
====================================

Q1: 启动时提示"未找到配置文件"？
A1: 运行 install.bat 重新配置

Q2: 提示"数据库连接失败"？
A2: 检查 .env 中的 DATABASE_URL 是否正确
    检查 SQL Server 服务是否运行

Q3: 浏览器驱动下载慢？
A3: 检查网络连接
    关闭防火墙/杀毒软件后重试

Q4: 任务一直处于"等待中"？
A4: 检查是否有其他任务正在执行
    查看日志中的错误信息
    手动点击"立即执行"

Q5: 采集不到数据？
A5: 检查目标网站是否需要登录
    检查选择器是否正确
    查看日志中的详细错误

Q6: 如何查看详细日志？
A6: 日志位于 logs/ 目录
    实时日志在监控看板查看

十、注意事项
====================================

1. 数据安全
   - 定期备份数据库
   - 妥善保管 .env 文件（包含数据库密码）
   - auth_files/ 目录包含登录态信息，注意保密

2. 性能优化
   - 避免同时执行大量任务
   - 定期清理历史数据
   - 监控磁盘空间（日志会持续增长）

3. 网站变化
   - 目标网站改版可能导致采集失败
   - 需要更新配置中的选择器

4. 合规使用
   - 遵守目标网站的使用条款
   - 控制访问频率，避免对服务器造成压力
   - 仅用于合法的数据采集用途
