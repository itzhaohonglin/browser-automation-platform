【核心配置项】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. DATABASE_URL（必填）
   数据库连接字符串

   格式：
   mssql+aioodbc://用户名:密码@服务器:端口/数据库?driver=驱动

   示例：
   DATABASE_URL=mssql+aioodbc://sa:Pass123@localhost:1433/bap?driver=ODBC+Driver+17+for+SQL+Server

2. APP_PORT（可选，默认 8000）
   Web 服务端口

   修改方法：
   APP_PORT=9000

   生效方式：
   重启服务即可，无需重新打包

3. HEADLESS_MODE（可选，默认 true）
   浏览器是否后台运行

   选项：
   HEADLESS_MODE=true   # 后台运行（推荐）
   HEADLESS_MODE=false  # 显示窗口（调试用）

4. LOG_LEVEL（可选，默认 INFO）
   日志详细程度

   选项：
   DEBUG | INFO | WARNING | ERROR

【常见场景】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

场景1：修改端口
─────────────────
需求：将默认 8000 改为 9000
修改：.env 文件中设置 APP_PORT=9000
重启：Ctrl+C 停止，再运行 startup.bat
访问：http://127.0.0.1:9000/static/index.html

场景2：连接远程数据库
─────────────────
需求：连接到 192.168.1.100
修改：DATABASE_URL=mssql+aioodbc://user:pass@192.168.1.100:1433/bap?driver=ODBC+Driver+17+for+SQL+Server
前提：远程数据库开放 1433 端口

场景3：启用调试模式
─────────────────
需求：查看详细日志
修改：
  DEBUG=true
  LOG_LEVEL=DEBUG
  HEADLESS_MODE=false
效果：显示详细日志 + 浏览器窗口可见

场景4：密码包含特殊字符
─────────────────
问题：密码 P@ss#123 导致连接失败
解决：使用 URL 编码
  @ → %40
  # → %23
  % → %25
  空格 → %20
结果：P%40ss%23123

安装前：
□ SQL Server 服务运行中
□ 数据库 bap 已创建（CREATE DATABASE bap COLLATE Chinese_PRC_CI_AS;）
□ ODBC Driver 17 已安装

配置 .env：
□ DATABASE_URL 已修改（必填）
□ APP_PORT 已设置（可选）
□ 密码特殊字符已编码

首次启动：
□ 运行 install.bat 完成安装
□ 运行 install_browser.bat 下载浏览器驱动（300MB）
□ 运行 init_database.bat 初始化数据库表

日常使用：
□ 运行 startup.bat 启动服务
□ 访问 http://127.0.0.1:端口/static/index.html
□ Ctrl+C 停止服务

错误1：数据库连接失败
检查：
  ✓ DATABASE_URL 格式是否正确
  ✓ SQL Server 服务是否运行（services.msc）
  ✓ 用户名密码是否正确
  ✓ 数据库 bap 是否存在
  ✓ ODBC Driver 是否已安装

测试：
  sqlcmd -S localhost -U sa -P 你的密码 -Q "SELECT @@VERSION"

错误2：端口被占用
检查：
  netstat -ano | findstr ":8000"

解决：
  修改 .env 中的 APP_PORT 为其他端口

错误3：修改配置不生效
原因：
  未重启服务

解决：
  Ctrl+C 停止服务，重新运行 startup.bat

错误4：浏览器驱动下载慢
解决：
  方案1：设置镜像源后重新安装
    set PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright
    install_browser.bat

  方案2：离线安装（从其他机器复制）
    复制到：C:\Users\用户名\AppData\Local\ms-playwright\
