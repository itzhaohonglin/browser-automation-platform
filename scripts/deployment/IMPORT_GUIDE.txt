========================================
1. 工具简介
========================================

数据导入工具用于批量导入采集任务。

主要功能：
✓ 支持多种文件格式（文本、Excel、CSV）
✓ 自动去重
✓ 批量创建任务
✓ 智能错误检查

适用场景：
- 批量导入注册证号
- 批量导入关键词
- 批量导入查询参数

========================================
2. 支持的文件格式
========================================

格式 1：纯文本文件 (.txt)
  - 每行一个值
  - 支持注释行（# 开头）
  - 空行自动忽略

格式 2：Excel 文件 (.xlsx, .xls)
  - 必须包含表头（列名）
  - 支持多列（指定导入哪一列）
  - 自动过滤空值

格式 3：CSV 文件 (.csv)
  - 逗号分隔
  - UTF-8 编码
  - 第一行为列名

========================================
3. 使用方法
========================================

方法 1：图形界面（推荐）
----------------------------------------
双击运行：import_data.bat

按照提示选择：
  1. 从文件导入注册证号（推荐）
  2. 从 Excel 文件导入
  3. 从 CSV 文件导入
  4. 手动输入注册证号
  5. 查看导入模板

方法 2：命令行
----------------------------------------

文本文件导入：
  python scripts\import_data.py ^
    --file data.txt ^
    --config-id 44

Excel 导入：
  python scripts\import_data.py ^
    --excel data.xlsx ^
    --column "注册证号" ^
    --config-id 44

CSV 导入：
  python scripts\import_data.py ^
    --csv data.csv ^
    --column "注册证号" ^
    --config-id 44

========================================
4. 文件格式要求
========================================

文本文件示例 (registration_numbers.txt)
----------------------------------------
# 注册证号列表
# 井号开头为注释，不会被导入
滇械注准20192140008
京械注准20210001234
沪械注准20200005678

# 可以添加更多...


Excel 文件示例
----------------------------------------
需要包含"注册证号"列（列名可自定义）：

| 序号 | 注册证号              | 备注     | 其他列 |
|------|-----------------------|----------|--------|
| 1    | 滇械注准20192140008   | 需要查询 | ...    |
| 2    | 京械注准20210001234   |          | ...    |
| 3    | 沪械注准20200005678   | 优先     | ...    |

注意事项：
  - 第一行必须是列名
  - 只会导入指定的列
  - 其他列会被忽略
  - 空行会被跳过


CSV 文件示例 (registration_numbers.csv)
----------------------------------------
注册证号,备注
滇械注准20192140008,需要查询
京械注准20210001234,
沪械注准20200005678,优先

注意事项：
  - 必须是 UTF-8 编码
  - 使用逗号分隔
  - 第一行为列名

========================================
5. 常见问题
========================================

Q1: 提示"配置ID不存在"
----------------------------------------
错误：[错误] 配置ID 44 不存在

解决方案：
1. 确认配置是否已创建
   访问: http://127.0.0.1:8000/api/configs

2. 如果未创建，先运行初始化脚本：
   python scripts\init_nhsa_registration_config.py

3. 使用正确的配置ID
   --config-id 实际的配置ID


Q2: Excel 导入失败，提示找不到列
----------------------------------------
错误：[错误] Excel 文件中未找到列: 注册证号

解决方案：
1. 检查列名是否正确（区分大小写）

2. 查看 Excel 第一行的列名

3. 使用正确的列名：
   --column "实际的列名"


Q3: 文件编码错误
----------------------------------------
错误：UnicodeDecodeError

解决方案：
1. 确保文件是 UTF-8 编码

2. Windows 记事本保存时选择：
   文件 -> 另存为 -> 编码选择 UTF-8

3. 或使用专业编辑器（VS Code、Notepad++）


Q4: 导入后任务不执行
----------------------------------------
现象：任务状态一直是 pending

解决方案：
1. 手动触发执行
   前端看板 -> 点击任务 -> 执行

2. 使用 API 执行
   curl -X POST http://127.0.0.1:8000/api/jobs/任务ID/execute

3. 等待调度器自动执行
   每30分钟自动扫描 pending 任务


Q5: 大量数据导入很慢
----------------------------------------
现象：导入几百条数据需要很长时间

优化建议：
1. 分批导入
   每次导入 100-200 条

2. 检查数据库性能
   确保数据库连接正常

3. 使用 SSD 硬盘

6. 高级用法
========================================

指定自定义参数名
----------------------------------------
默认参数名是 "registration_no"，可以自定义：

python scripts\import_data.py ^
  --file data.txt ^
  --config-id 44 ^
  --param-name "custom_field_name"

注意：参数名必须与配置中 input_configs 的
     param_name 字段匹配


批量导入多个配置
----------------------------------------
为不同配置导入数据：

REM 配置1：注册证号查询
python scripts\import_data.py ^
  --file registration_numbers.txt ^
  --config-id 44

REM 配置2：产品名称查询
python scripts\import_data.py ^
  --file product_names.txt ^
  --config-id 45 ^
  --param-name "product_name"


导入后立即执行
----------------------------------------
导入完成后，可以使用批处理脚本批量执行：

@echo off
REM 假设导入的任务ID为 100-200

for /l %%i in (100,1,200) do (
  curl -X POST http://127.0.0.1:8000/api/jobs/%%i/execute
  timeout /t 2 >nul
)


检查导入结果
----------------------------------------

查询任务数量：
curl http://127.0.0.1:8000/api/jobs?config_id=44

查询 pending 任务：
curl http://127.0.0.1:8000/api/jobs?status=pending

查询成功任务：
curl http://127.0.0.1:8000/api/jobs?status=success


导出失败任务
----------------------------------------
如果有任务失败，可以导出重新处理：

1. 访问 API 文档
   http://127.0.0.1:8000/docs

2. 使用 GET /api/jobs?status=failed

3. 提取失败任务的查询参数

4. 重新创建文件导入

模板文件
========================================

使用工具生成模板
----------------------------------------
运行 import_data.bat，选择"5. 查看导入模板"

会自动生成：
  - registration_numbers_template.txt
  - registration_numbers_template.csv

直接编辑这些模板文件即可使用


手动创建模板
----------------------------------------

文本模板 (data.txt)：
  注册证号1
  注册证号2
  注册证号3

Excel 模板：
  第一行: 注册证号
  第二行开始: 数据

CSV 模板 (data.csv)：
  注册证号
  数据1
  数据2
